# 常用格式兼容补测报告

验收日期：2026 年 10 月 25 日。[打开 HTML 版](2026-10-25-common-formats.html)。

**36 组样本在 Android 手机模拟器、Android TV 模拟器、iPhone、iPad 和 macOS 五个环境全部通过，共 180 次应用播放检查。Android 的 MLP 失败已修复。**

## 一、本轮修复

- **修复 Android 共用渲染链路**：原先 MLP 已经解码并打开声音，但 EGL 上下文参数被驱动拒绝，普通 H.264 也会在同一路径失败。现由本地适配器探测真实驱动行为，命中该问题时启用兼容参数；结果缓存，核心等待上限 1 秒。
- **保留完整解码器**：继续使用固定版本完整 libmpv/FFmpeg，修复同时作用于普通和强制软解路径。
- **加强播放检查**：视频要求上游通知、输出已配置、有效输出参数与时钟推进，并捕获致命错误。纯音频按清单跳过视频要求，仍检查声音与播放推进。
- **扩大固定矩阵**：从原有 18 组基础样本扩充到 36 组，加入 HE-AAC/v2、常用纯音频、FLV/MP3、AAC LATM、HLS fMP4 和编码尺寸 720p/1080p。

EGL 兼容参数只在“零标志属性返回 EGL_BAD_ATTRIBUTE、普通与 DEBUG 上下文均可创建”时启用，正常驱动使用原设置。DEBUG 上下文可能增加驱动检查开销。后续原生库升级应复核并评估移除这一兼容处理。

## 三、常用格式覆盖

| 类别 | 本轮明确覆盖的样本 |
| --- | --- |
| 直播与封装 | HLS 的 TS/fMP4 分片、DASH、FLV、TS、MP4、MKV、MOV、WebM、AVI、ASF、Ogg、WAV |
| H.264 / HEVC | H.264 Baseline、High（编码 1920×1080）；HEVC Main（编码 1280×720）、Main10 |
| 其他视频 | VP8、VP9、AV1、MPEG-2、MPEG-4、WMV2 |
| 直播音频 | AAC LC、AAC LATM、HE-AAC、HE-AAC v2、MP2、MP3 |
| 多声道与无损 | AC-3、E-AC-3、TrueHD、TrueHD 5.1、MLP、DTS、FLAC、ALAC |
| 其他音频 | Opus、Vorbis、PCM、WMA2 |
| 纯音频 | AAC、MP3、FLAC、ALAC、Opus、Vorbis、PCM、HE-AAC、HE-AAC v2，共 9 组 |

HE-AAC/v2 使用本包自行生成并固定 SHA-256 的正弦波音调，所有平台使用同一输入。720p/1080p 指编码尺寸；缩放样本保留合成输入的显示比例，包含非方形像素。常规基础样本为 160×96，所有样本约 4 秒。

## 五、解码与声音的额外证据

| 检查 | 结果 | 验证范围 |
| --- | --- | --- |
| 独立包自动化测试 | 109 项通过 | EGL 探测降级、源、策略、会话与原生库固定等 |
| 应用全量自动化测试 | 170 项通过 | 应用的播放器、状态及其他现有回归；与包内测试有复用 |
| 静态检查 | 通过 | 独立包，以及修改涉及的宿主后端与探针 |
| macOS 原生 decoder 矩阵 | 36 / 36 | 独立的无窗口、无声音输出解码检查；包含 9 组纯音频 |
| HTTP/HLS 传输回归 | 5 / 5 | 默认 UA、重定向、签名、多码率恢复、慢首字节与 403 识别 |
| 调试构建 | Android、iOS 模拟器、macOS 完成 | macOS 测试副本使用独立 bundle ID 与 ad-hoc 签名 |

**Android MLP 画面与声音专项通过。** 在主矩阵之外，用 20 秒 H.264 + MLP 样本检查至少 10 秒播放推进；修正验收工具的小窗口布局后，截图确认测试图按比例居中显示。

随后采集 12 秒系统混音：静音基线 RMS 为 0，MLP 播放 RMS 为 0.010337（-39.71 dBFS），检出非静音 PCM。采样时其他本轮测试播放器均已停止。此专项独立于上面的 180 项计数。

## 六、验收边界与后续

- Windows / Linux 的 CI 已使用同一生成器，覆盖 36 组；本轮没有在这两个系统执行运行验收。
- Android 手机、Android TV、iPhone、iPad 本轮使用模拟器。实际手机、平板、电视、旧系统版本和不同 GPU 仍需各自验收。
- 高码率 4K/8K、HDR、长期直播、断网恢复、蓝牙/HDMI、口型同步和真实多声道输出仍需要专项测试。
- TrueHD 5.1 验证了解码与 PCM 输出；Atmos 对象渲染、HDMI 原码透传和真实 5.1 扬声器待验收。
- 本轮验证格式与共用渲染修复，上轮全部直播地址未重新执行；过期授权、404 与供数不足仍需要有效上游内容。历史直播结果保留在原报告。
