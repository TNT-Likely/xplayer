# 边界状态与恢复规则

这份规范定义目标体验。HTML 可通过顶部「边界状态」切换代表场景；网络、播放与设备连接仍为演示，不能将演示反馈直接作为业务实现。

## 基本原则

1. **EPG 与播放独立。** 没有节目单、解析失败或更新失败，都不能阻止已有频道直播。不要用覆盖播放器的错误弹窗提示 EPG 问题。
2. **空数据不等于失败。** 未配置、合法空响应、频道映射失败、网络错误、数据过期分别说明原因与下一步。
3. **可用内容先保留。** 请求失败不清空已有列表、收藏或仍在有效时间范围内的 EPG；新数据验证成功后再替换。
4. **只说已知事实。** 没有 EPG 时显示频道身份与“暂无节目单”，不猜测节目名称、起止时间、进度或接下来节目。
5. **反馈有恢复入口。** 能重试则提供重试；需要配置或权限时说明入口；不可恢复时允许返回或换频道。后台失败不反复打断用户。

## EPG 状态矩阵

| 状态 | 判定 | 界面与播放 | 主操作 / 次操作 |
| --- | --- | --- | --- |
| 未配置 | 当前列表没有可用 XMLTV 关联 | 引导配置，保留频道播放；不自动认定源失效 | 配置节目单 / 浏览频道 |
| 首次加载 | 请求或解析进行中且无缓存 | 加载提示与频道入口；不先显示“暂无数据” | 先看频道 |
| 刷新中，有缓存 | 请求进行中且现有快照可用 | 继续显示缓存，更新入口进入忙碌状态 | 取消或等待，不发起重复请求 |
| 成功但无节目 | 数据合法，但所选日期/频道无节目 | 说明暂无匹配数据；保留频道，不显示虚构时间轴项目 | 刷新 / 浏览频道 |
| 请求失败，无缓存 | 断网、超时、HTTP 错误且无快照 | 显示失败原因与最近尝试时间；直播不受 EPG 失败影响 | 重新获取 / 先看频道 |
| 请求失败，有有效缓存 | 更新失败，但缓存覆盖当前查询时段 | 原有表格保留；标明“缓存于…”和更新失败 | 重试更新 |
| 缓存过期 | 快照不再覆盖当前日期或查询时段 | 明确显示缓存日期；不标“正在播出”，不画当前时间线或节目进度 | 更新 / 浏览频道 |
| 部分频道缺失 | 部分频道匹配成功，其他未匹配 | 已知节目正常显示；缺失行保留频道名、播放入口与“暂无节目信息” | 重新匹配 / 单独观看频道 |
| XML/压缩数据无效 | 下载成功但解析失败 | 作为获取失败展示“格式无法识别”；已有有效快照不丢失 | 检查地址 / 重新获取 |
| 没有所选日期 | 有其他日期数据，当前日期无数据 | 显示日期与覆盖范围，允许返回今天或有数据日期 | 返回今天 / 切换日期 |
| 时间重叠或空档 | 上游节目区间不连续或冲突 | 空档不补造节目；冲突以稳定规则选一条并保留诊断 | 播放频道 / 刷新 |

### EPG 细节

- 缓存可用性取决于数据覆盖的时间区间，不单凭“获取于今天”判定。过期缓存不可伪装成当前节目。
- 缓存须关联列表 ID、EPG 源、频道匹配键、获取时间、覆盖区间和时区，避免切换列表后显示另一来源的旧节目。
- XMLTV 时间先按其偏移转成绝对时间，再按设备时区显示；跨午夜、夏令时和设备时区变化不改变节目的实际顺序。
- 若部分频道更新失败，不应清空其他频道的有效节目。无匹配频道应保留位置，便于 TV 焦点稳定。
- 多次刷新只保留有效的最新请求结果；切换源/列表后忽略旧请求的迟到响应。
- 无 EPG 时，首页、频道卡片、迷你播放器和播放器同步隐藏未知的节目名、起止时间、节目进度与“接下来”；保留频道名、真实播放状态和可用清晰度。
- EPG 的节目进度是信息展示；它不表示直播一定支持拖拽或时移。可时移范围需要独立标识。
- 原型的 XMLTV 配置入口会检查 http/https 地址；正式实现还须区分地址格式、认证、代理、TLS、下载和解析错误。

## 其他边界

| 分类 | 情况 | 目标表现与恢复 |
| --- | --- | --- |
| 网络 | 无网络 / 网络切换 | 保留本地列表和收藏；在线内容说明离线。正在播放能继续则不主动打断；真实断流再显示播放恢复操作 |
| 播放 | 首次连接 | 显示频道名与连接状态，允许取消或换台；不提前显示播放成功或 EPG 进度 |
| 播放 | 短暂缓冲 | 保留最后一帧并说明缓冲；不把正常缓冲误报为终止错误 |
| 播放 | 持续缓冲 / 断流 | 提供重连和换台；自动重试应有上限，并显示最终停止重试的状态 |
| 播放 | 格式或解码能力不支持 | 提供兼容播放入口或换源；保留诊断信息，不无限重复相同失败路径 |
| 播放 | 仅音频 | 呈现频道身份与音频控制，正常收听不当作“黑屏故障” |
| 播放 | 有画面无声音 / 音轨缺失 | 保留画面，提供可用音轨、音量与兼容处理；无可选音轨时隐藏切换项 |
| 播放 | 无多码率 / 无多音轨 | 控件只展示真实可选项；不展示无法兑现的 4K 或语言选项 |
| 播放 | 401 / 403 / 地域限制 | 说明源访问受限，允许检查源配置或换源；避免无意义的持续重试 |
| 播放 | 切台时旧请求迟到 | 新频道拥有当前播放控制权，旧响应不覆盖新频道标题、状态或画面 |
| 列表 | 首次启动 / 尚无频道 | 提供添加 URL、导入文件和推荐源入口；不展示假频道填充空界面 |
| 列表 | 导入地址无效 / 空文件 / 解析失败 | 原列表与收藏保留；错误靠近输入或当前列表，保留已输入地址便于修改 |
| 列表 | 部分条目无效 | 显示成功数与跳过数，可查看简要原因；不将部分成功写成全部失败 |
| 列表 | 重复导入 / 删除当前列表 | 先说明合并、替换或保留行为；删除后选择合法的剩余列表，避免空 ID 与焦点悬空 |
| 列表 | 文件权限被拒 / 文件已移走 | 保留其他列表，重新选择文件；不不断弹出文件选择器 |
| 搜索 | 无结果 | 保留关键词和分组说明，提供清除筛选；不与“列表无频道”共用同一错误文案 |
| 收藏 | 无收藏 / 收藏频道被源移除 | 空收藏引导找频道；失效收藏保留标识与移除操作，不跳到错误的同名频道 |
| 画面 | 无频道 Logo / 无节目图 | 使用中性底色与频道名称，不留破图或假节目封面；示例图片不作为正式产品必要依赖 |
| 遥控 | 未发现设备 | 说明同一 Wi-Fi、TV 已打开 XPlayer 等条件，提供重新搜索与手动连接 |
| 遥控 | 局域网权限受限 | 区分“权限未允许”和“没有设备”，提供系统设置指引；未经许可不展示已连接或可操作的遥控器 |
| 遥控 | 连接超时 / 设备离线 | 停止发送按键，说明断开并提供重连；不显示虚假的发送成功 |
| 同步 | 配置冲突 | 逐项显示差异并勾选；确认后才应用。取消不改变现有配置，失败时不留下半份覆盖结果 |
| 设置 | 已选画质或音轨消失 | 回到可用默认值并说明变化；播放继续时避免强制弹窗 |
| 设备 | 旋转 / 分屏 / 窗口变窄 | 保留选中频道、播放状态、搜索词和合理滚动位置；不因布局切换重新连接直播 |
| TV | 数据刷新后焦点项消失 | 焦点移到同组相邻可用项或组标题，始终可见；返回恢复合理位置 |
| 可访问性 | 大字体 / 长频道名 / 减少动态 | 核心操作不截断、不依赖颜色；允许滚动，加载动效可停用，语义状态及时更新 |

具体请求超时、重连次数、退避和内核回退策略复用相应服务层的配置。本设计资源不另行引入与播放器策略冲突的固定阈值。

## 状态组合与优先级

- **离线 + 有缓存 EPG：** 顶部说明离线，缓存标明获取时间；过期则同时标日期，不把旧内容标作当前节目。
- **EPG 失败 + 直播正常：** 直播持续，EPG 区域局部提示。播放控制不进入错误状态。
- **部分 EPG 缺失 + 收藏频道：** 收藏与频道入口保留；缺失元数据不会删除收藏。
- **播放失败 + EPG 正常：** 节目仍可浏览，但播放面板不能暗示已成功播放。
- **当前列表被删除 + 迷你播放器：** 先按产品播放生命周期策略决定继续当前流或停止，再更新浏览列表；不让 UI 持有已删除列表引用。
- **手动重试进行中：** 当前按钮进入忙碌状态，阻止重复请求；失败后恢复操作，不永久锁住页面。

## 交付与验收

HTML 中的状态目录保存在 `prototype/states.js`。代表场景可复制带 `state` 参数的链接，并切换四端。边界状态仅扩充 A，B/C 保留原有概念。Figma 对应状态使用可编辑文本和原生图层；完整实时交互以 HTML 为准。

验收至少覆盖：无 EPG 不出现虚构节目进度；EPG 获取失败仍可播放频道；缓存错误与缓存过期文案不同；重试可恢复；部分缺失按行提示；离线不清除本地内容；播放失败可退出/换台；权限拒绝不伪装成未发现设备；同步取消不更改配置。
