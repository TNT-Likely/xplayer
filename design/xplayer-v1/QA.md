## HTML

- 最终遍历手机、iPad、桌面、TV 的 21 类边界场景，共 84 个组合，见 qa-browser.json。主体无意外横向溢出，EPG 本身保留必要横向滚动。
- 尚无播放列表时，不展示示例频道填充空界面；空收藏与空列表使用临时演示数据，不覆盖浏览器中保存的正常收藏与列表。
- 无 EPG 隐藏未知节目时间、节目进度与接下来节目；获取失败仍保留频道入口。
- 过期缓存标记昨日日期，无当前时间线或节目进度；部分缺失按 3 个频道分别说明。
- 已验证 EPG 重试经过加载恢复、XMLTV 地址拒绝非 http/https、频道搜索、收藏、播放器开关和多端页面导航。
- B/C 切换保留原有方案，边界选择器禁用并回到正常状态。

## Figma

- A 共 74 个完成画板，按首页、播放器、各端核心页面和边界场景分区。
- 主体为可编辑文本、矢量图标、原生框架、图片填充和组件实例；没有把整屏截图作为设计稿。
- 四端核心导航与观看入口连接为原型，4 个设备流程起点。
- 导入后检查并修正时间标签堆叠、按钮编排、错误图标居中、品牌换行、侧栏颜色及分隔线。
- 精细时间轴采用固定位置，以保留节目时长与横向比例。Figma 与系统中文字体存在字形及行高差异；精确交互以 HTML 为准。

## 实现边界

HTML 不接入真实 IPTV 播放、下载与解析、系统权限、设备发现、遥控发送或同步服务。重试和成功反馈为可体验的设计模拟。EDGE-CASES.md 另外定义了解析错误、时区与跨日、长文本、请求竞态、权限拒绝、焦点恢复和组合状态，供实现和验收使用；这些规则不都单独扩展成画板。
