# 组件与交互状态

## 资源范围

HTML 是完整交互示例；Figma 中的共享组件用于复用实际按钮、导航、分组、频道卡片和直播标记。状态展示与业务能力分开记录，避免把设计演示当作已经接入的功能。

| 组件 | 主要属性 | 已展示状态 | 产品实现需补充 |
| --- | --- | --- | --- |
| 主按钮 | 主题、尺寸、标签、图标 | 默认、悬停、焦点、点击反馈 | 按操作补充禁用与加载 |
| 导航项 | 设备、目标、选中 | 默认、选中、焦点 | TV 焦点恢复、各平台返回行为 |
| 分组标签 | 标签、数量、选中 | 默认、选中、横向滚动 | 超长分组及源更新后的恢复 |
| 频道卡片 | 频道、节目、画面、进度、收藏 | 默认、收藏、悬停播放入口 | 画面缺失、源失效、无节目单 |
| 直播标记 | 主题、标签 | 正在直播 | 连接中、断流、重试 |
| 收藏按钮 | 频道、收藏状态 | 已收藏、未收藏、反馈 | 存储失败和跨设备冲突 |
| 搜索框 | 关键词、结果 | 输入、即时筛选、无结果 | 大数据列表性能和输入法行为 |
| EPG 项目 | 频道、开始/结束、当前/未来 | 当前、未来、节目详情 | 无数据、跨天、时区、源数据错误 |
| 播放控制 | 暂停、画质、音轨、定时 | 暂停/继续、选项、边看边选 | 真实缓冲、错误、轨道能力限制 |
| 迷你播放器 | 当前频道、暂停状态 | 收起、展开、暂停、关闭 | 真实音视频生命周期 |
| 播放列表 | 名称、URL/文件、选中 | 新增、编辑、移除、切换 | 导入校验、下载/解析进度、失败 |
| 遥控器 | 方向、确认、返回、文本 | 按键与文字发送反馈 | 设备发现、连接状态、超时 |
| 设置开关 | 标签、开启 | 开启、关闭、本地记忆 | 与实际设置服务联动 |

## 键盘与触控

- Tab 在当前弹窗或播放器内循环；Esc 先关闭弹窗，再返回浏览，最后返回首页。
- `/` 聚焦搜索。输入框内不拦截普通按键。
- Space 只在播放器中切换播放状态。
- TV 的方向键按空间关系移动焦点，Enter 激活当前项。产品实现需验证遥控器实体返回键映射。
- 收藏、关闭、搜索等纯图标操作保留可访问名称，选中状态使用 `aria-pressed` 或等价平台语义。

## 演示边界

播放画面是静态图片。清晰度、音轨、睡眠、投屏、局域网同步和遥控均展示选择或反馈流程，没有连接真实播放流或设备。播放列表和收藏仅保存于当前浏览器本地。切换界面语言只展示入口，当前交付为中文稿。
